# Nirvana Rover

An open-source autonomous environmental exploration rover powered by ESP32 and Raspberry Pi.

---

## Overview

Nirvana Rover is a modular robotics platform designed for environmental sensing, autonomous navigation, and real-time data processing.

The project combines:
- ESP32 for low-level embedded control
- Raspberry Pi for high-level processing and intelligence
- Modular electronics architecture
- Expandable sensor systems

The goal of the project is to create a fully documented and reproducible rover platform that anyone can build from scratch.

---

## Features

- Autonomous obstacle detection
- Environmental sensing
- ESP32 motor and sensor control
- Raspberry Pi high-level computation
- Modular hardware architecture
- Open-source firmware and electronics
- Expandable design for future AI and vision systems

---

## System Architecture

Sensors → ESP32 → Raspberry Pi → Navigation & Analysis

The ESP32 handles:
- Sensor reading
- Motor control
- Real-time embedded operations

The Raspberry Pi handles:
- High-level processing
- Future vision systems
- Telemetry
- Advanced navigation logic
